# Recipes

Step-by-step setups for the inboxes and connections added in 0.3.0.

| Recipe | What it sets up |
|---|---|
| [Paperless-ngx](paperless-ngx.md) | Documents tagged `health` in Paperless arrive in the review queue, linked back |
| [Scanner to folder](scanner-to-folder.md) | A scanner or a synced phone folder drops files that are imported per profile |
| [Health Auto Export](health-auto-export.md) | An iPhone pushes Apple Health data every 15 minutes |
| [Nightscout](nightscout.md) | Continuous glucose readings pulled from your Nightscout site, with a CGM summary |
| [iOS Shortcut](ios-shortcut.md) | Share a photo or PDF from an iPhone straight into OwnHealth |
| [claude.ai connector](claude-connector.md) | claude.ai reads OwnHealth through MCP, over a tunnel, with OAuth |

For scans without the `ocr` profile, see [agent-assisted extraction](../agent-extraction.md). For alerts when an inbox stops syncing, see [Monitoring the inboxes](../../deploy/README.md#monitoring-the-inboxes).
